# 效果图识别与关键构件试建

用于八步路径的第3步及第5步。效果图证据约束造型；平面和已确认尺寸约束定位。两者冲突时留账协调，不用通用模板悄悄覆盖图像特征。

## 分区取证与规格表

使用可获得的最高分辨率原图，按主屋顶、低侧房、入口首层、入口上层、檐口、栏杆等分区放大。裁剪记录原图路径和区域，截图放大不能恢复原图没有的细节。

每项规格至少记录：`构件/实例ID、图像路径与局部区域、可见特征、类型候选及采用依据、数量、部件组合、比例、附着位置、前后遮挡、平面约束、采用参数及来源、未定项`。视觉比例不直接当作毫米实测尺寸。

- 屋面：檐口边界、屋脊端点及方向、坡面数量、山墙/斜坡端、与主体墙面或相邻屋面交接。矩形长宽只能辅助提出候选，不能代替识别。单张透视中的斜线不能直接搬成正立面斜脊。
- 柱：按楼层/区域分别确认方柱、圆柱或成对圆柱，以及基座、柱身、柱头、浮雕和线脚的组合与分段比例。上下层对齐不代表柱型相同。
- 檐口与栏杆：记录线脚层次、挑出、托件、柱墩位置及支承关系；不是只查构件是否出现。
- 未见区域：标记遮挡或缺证，保留有依据的候选。需要采用推定时明确其影响，不能称为已识别事实。

## 试建后再批量生成

### 雨棚类型与附着关系专项核对

后续项目逐个雨棚执行以下核对，不继承旧项目的雨棚形式、坡度、高度、退距或背板尺寸：

1. **先辨类型再套模板。**结合原生平面、构件属性、文字、标高/节点及效果图局部，区分平板、单坡、贴墙坡棚、完整四坡门罩等有据候选。平面外轮廓或“雨棚”名称不能单独确定坡面形式；不同建筑效果图的门罩组合不能未经定位核对移植到本案。
2. **逐段确认边界角色。**保留原线开闭状态和实体句柄，登记自由边、接墙边、接梁/板边、阳台相接边及其宿主实例。同一条后沿可分属不同宿主。几何计算需要补闭轮廓时，补边仅为计算边界，不能自动认定为自由檐或据此生成后坡。
3. **核实标高所指控制面。**明确原标高指向板顶、板底、檐口、墙边或其他节点；源值、采用语义和新增坡度/厚度分开记录。未明标高不能直接作为檐口再推算屋脊，也不能用方案板厚反推出板底后称其为源节点。
4. **核对真实附着与组合。**以共同坐标记录雨棚后沿、宿主墙/梁/板、阳台边、门洞、门楣及柱的XY范围、前后退距和起止标高。检查它们实际接触、承托或连接的区间，区分投影重合与三维相接；独立雨棚也须有其独立支承依据。新增背板/连接件须有节点或明确方案依据，不能只为模型接触或轮廓闭合而补建。造型连接不冒充结构承载已核定。
5. **前置试建与更新后回核。**试建包括雨棚和真实宿主、相邻板边/墙段、门头及支承，核对平面、附着端及门洞处竖向剖面、关键标高水平截面和四向正投影。整体更新后再反核源平面及节点；分别记录类型、边界角色、标高语义、真实连接、投影和导出结论。缺证列候选/推定，类型或宿主未解决不得写“已通过”；零开放端、零重线、同模型遮挡自检和AUDIT不能代替关系核定。

### 中式屋檐的连续起翘

辨别连续上扬的屋面/檐口与独立装饰件。逐区记录平檐转入起翘的位置、过渡跨度、切线及曲率趋势、层次厚薄、屋脊端部和檐角的区别、与相邻坡面和斜脊的衔接。主屋顶、低侧房及入口门罩不能无条件共用同尺寸模板。参考图的可见类型与毫米方案参数分列，不把透视长度当实测值。

试建必须包括完整起翘过渡、相邻坡面及檐板，检查连续接点、最终有效面邻接、檐口各层的共同控制曲线和四向遮挡。连续起翘不能用独立四面体、三角片、仅抬高尖角或二维补斜线代替；网格只用于曲面及遮挡计算，不将三角剖分边或密排线输出。曲线采样须有误差依据并连接为可编辑连续轮廓，不能把大量碎线包装成曲线。

### 窗套的宽度、深度与出图意图

套边宽度优先采用平面或已确认节点，缺失时默认100mm并注明缺省依据；该值不代表出墙深度、框宽或洞口扩大。窗套在视线平行于其宿主墙面的侧立面中不显示厚度线。按宿主墙面法向和观察方向确定适用视向，按实例控制出线和遮挡，保留物理几何记录。普通装饰窗框的侧向厚度可按同样方法省略。正面轮廓、分格和真实侧向洞口保持来源关系；真实突出体量或承托构件另行核定，不能按图层全删。避免省略轮廓后仍由同一装饰厚度遮挡其他实体形成假断口，表达模型及遮挡策略须一致并验证。

1. 对屋顶、入口柱及本项目其他关键/歧义构件先建立简化几何；将规格表中的特征关联到模型参数，不先套模板再为结果找依据。
2. 使用关键标高的水平截面、竖向剖面和四向正投影验证尺寸、附着及遮挡；原图局部用于确认类型、组合和可见特征。不得以相机匹配、透视预览或透视叠合进行试建校核，不把效果图的透视斜边直接搬到立面。
3. 单图缺证的深度、截面及隐藏关系列为候选/推定，结合原平面及已确认节点核定；生成截面不能自证模型有依据。核对记录标明证据和限制，不声称已由单图还原全部几何。
4. 发现不符先区分类型选错、组合错误、参数比例错误、位置或遮挡错误，再修改对应源参数。未定类型不能静默落入默认模板。
5. 试建结论写回规格表，再生成统一几何及四向严格正投影。第5步仍须用整体结果逐项回核，不能以试建替代。

## 验证依据

逐项给出类型、数量、组合、比例、位置、遮挡六方面的检查结果及图像定位，并保存平面、截面、剖面和正投影核对依据。

## 前后柱及其他重叠构件的专项核对

1. 读取原生柱的实际轮廓及定位基准。L形、T形等截面不以外包矩形代替；包柱作为独立装饰完成面，记录宿主、范围、厚度及依据。
2. 在柱身、柱墩、柱帽等关键标高取水平截面，并核对相应竖向剖面。记录前后柱、壁柱、栏杆柱及墙体的中心偏差、深度差和完成面边界；投影重叠但XY不同的实例仍须跨组检查。
3. 发现额外长线或柱条，先由最终实体/块追溯到实例及原边，计算正投影露出区间；再对照源平面和造型证据判断构件是否应存在、是否误将贴墙装饰建为完整柱。不能因为遮挡算法保留了线就认定构件设置正确。
4. 分别核验“模型按当前几何是否正确投影”和“当前几何是否符合设计依据”。修正存在性、轮廓或关联后再计算可见线；真实可见边保留，不能仅为图面整洁而删边、强制遮盖或移动原生柱。
5. 专项台账记录前后实例ID、原生句柄/图像证据、控制截面、完成面范围、投影露宽、采用结论及复核状态。复用该检查方法，不继承旧项目的中心偏差、包柱宽或处理结论。

本项目已发生的错误应进入后续同类项目的针对性复核：低侧房屋顶不得仅由平面长宽自动定型；入口首层方柱与上层成对圆柱须分别识别。复用检查方法，不把本项目的屋顶或柱型变成其他项目的固定答案。

## 屋面与四向异常线的独立核验

涉及坡面交接或四向断线/乱线时，读取[最终几何、屋面邻接与四向断线核查](geometry-topology.md)。试建须列出屋面控制和最终面/边归属；截面与源图、已确认条件交叉核对。效果图识别、同模型截面相互一致、遮挡自检及保存重开分别解决不同问题，不能互相替代。
