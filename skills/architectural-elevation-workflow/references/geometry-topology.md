# 最终几何、屋面邻接与四向断线核查

用于新建、修订及历史立面的第2、4、5—8步。复用判定方法，不复用某个项目的尺寸、坡度、柱型或处理结论。原模型及旧脚本是待核查输入，不是设计依据。

## 1. 先分开三个问题

1. **构件依据**：它是否应存在，其实际轮廓、宿主、位置、深度与完成面来自哪里？包覆、独立柱、贴墙线脚和图像推定分别记录。
2. **最终几何与拓扑**：组合、裁剪和合并以后，哪些面仍有效，哪些面相邻，哪里真有外边界、折角或设计接缝？
3. **投影与导出**：有效造型边如何被遮挡、截断、清理和成块？交付几何是否保留这些结果？

同模型遮挡自检只回答第3项的一部分；原生重开、AUDIT和块展开一致只验证保存保真。它们不能替代第1、2项。

## 2. 项目独立的屋面控制

先记录各屋面实例的来源、支承墙/板边、檐口边界与标高、坡面范围、坡向、坡度或起坡控制、屋脊端点和标高、屋谷、相邻屋面及设计接缝。标明平面已证、效果图可见、用户条件和方案推定。

- 不由矩形长宽自动决定脊向或完整四坡型，也不从透视斜边直接补正立面斜线。
- **同檐、同脊不表示坡面相容。** 按本项目的有效水平坡长和升高计算各面坡度，用平面、关键标高水平截面及纵横剖面核对后屋面是否露在前屋面之上、交接是否连续。计算方法依实际坡面类型，不能把对称四坡公式套给非对称或变坡屋面。
- 不同坡度、高低屋面及可见的前后斜边可以是有效设计；有本项目依据时保留。不能为少画一条线擅改坡度、屋脊或檐口，也不能一律要求同坡同高。条件相互冲突时登记需协调的具体参数，保留可核对的方案状态。
- 合并、裁剪或布尔运算只是几何过程；完成后仍要独立核定屋面整体关系，不能把两个完整坡顶取上包络就自动称为正确的屋面设计。

## 3. 只从最终有效面提取造型边

候选坡面及其两两交线仅供求交，不直接作为交付线源。完成面裁剪、同面合并和宿主关系处理后，建立最终面ID及邻接图，再提取轮廓、真实折线和有依据的接缝。

| 候选线的最终关系 | 处理 |
|---|---|
| 最终有效面的外边界/孔洞边界 | 保留来源，进入可见性计算 |
| 邻接有效面存在真实折角、脊谷或轮廓变化 | 保留，标明邻接面及类型，再计算遮挡 |
| 两侧实际可见面共面且无设计接缝 | 消除内部拼边，不能称屋脊或屋谷 |
| 共面但有明确的构造/材料/构件接缝依据 | 按该接缝表达，不作为坡面折线，也不因共面而误删 |
| 仅候选面相交，面已裁掉、无最终邻接关系或只沿边接触 | 不追加为交付折线；数值不确定时列疑点，不能凭标签保留 |
| 前后不同构件的真实边在投影上重合 | 先核存在性和深度，再明确可见区间及唯一归属，保留跨实例关联 |

曲面用其实际连续性和轮廓性质判定；不能套平面法向相等的规则。平面方程须统一单位和法向方向。分别登记距离容差、角度容差、物理单位、来源及适用尺度，设计角度差与浮点误差分开；不能继承上一项目的裸数值容差。

**禁止旧边回流**：完成最终面之后，旧候选交线、三角剖分边、布尔切片边不能绕过邻接判定重新追加。每个导出边指向其所属几何版本；面或构件改变后，使关联边及四向投影失效并重算。

## 4. 四个立面分别做端点与可见区间核查

交付前逐向检查断线、重线和无意义碎线。以重开 DWG 的实际实体及展开块作终检，覆盖墙、门窗及套线、前后柱、栏杆、屋面、檐口和线脚。先定位问题，再回溯原边，短线长度仅用于筛查疑点。

1. 建立四向线/解析曲线的接点与邻接关系。检查孤立长短线、悬空端点、接缝残边、T形交点、闭合轮廓意外开口、完全重复、共线部分重叠及跨实例断口。解析圆弧和椭圆的端点也参与检查。多段线已连接、实体数减少不表示轮廓正确。
2. 对每个截断区间，追溯遮挡构件/面、前后深度、原边参数区间及解析交点，核对它在前景轮廓处如何终止。可见性算法即使报告保留，也要检查原构件和该边是否有设计依据。
3. 依据证据分别判为：真实开放端、真实构造间隙、合理遮挡、T形接点、采样/浮点尾差、错误构件或完成面、无效内部边、裁剪错误、导出丢边、待定。不能按图层、实例名称或长度自动写“合理遮挡”。
4. 长短阈值只用于发现疑点。保留真实短边、原图小数及真实间隙；处理数值尾差时记录容差及依据，不全图取整、不按长度删线、不跨真实遮挡补线。未知原因不得靠提高容差或强制遮盖消掉。
5. 投影重叠但XY不同的实例必须跨组核查：同中心柱带检查不能覆盖前柱/后壁柱/墙体的组合。源L/T形等柱以原生轮廓为控制；包柱另有范围、厚度与定位依据，外包矩形中心不是原生定位基准。
6. 先修存在性、尺寸链、宿主、轮廓、深度、接缝或拓扑，再重算遮挡与四向投影；然后去重、连接和成块。不得只在交付二维图上手工删线而保留错误生成关系。

对曲线构件额外核对：洞口、内外框/套线、分格梃、玻璃及遮挡面共享同一套曲线控制与解析交点。梃端应与实际内框相交，不能以“外弧高减固定值”近似；也不能只把导出线换成解析弧，仍用不一致的旧采样轮廓挖洞/遮挡。有限采样用于显示或检测时，记录误差及其适用范围，不冒充精确连接证据。

对穿插节点额外核对：已有原边的隐藏裁切不会自动生成两个相交实体的新交接轮廓。柱/栏杆柱与斜檐、假坡、平台等相交时，先核定支承、避让、裁切或收口做法，再从最终三维面生成有依据的交接边，核验被截断竖线在何处承接。不能因旧边被正确遮挡，就把悬空端点判为合理；也不能未经节点核定直接补二维连接线。

### 按出图比例简化门窗型材细边

适用于方案深化、新建施工图立面和既有立面复修。以同一洞口为核查单位，在出图前核定型材表达，按目标比例在保存重开后验收。

1. **按纸面筛查。** 逐向读取实际比例、图纸单位和生效的出图线宽。纸面间距（mm）＝模型法向净距 × 每图形单位对应的毫米数 ÷ 比例分母。结合纸面间距、可见重叠区间和转角识别密线，覆盖长短不一、部分重叠和跨块的近距边。出图线宽缺少依据时记录待核项。几何重合容差用于坐标尾差和同线重复，纸面筛查阈值用于定位需要判断用途的线段。节点详图按自身比例和表达要求处理。
2. **识别主轮廓与细边。** 逐洞口把交付线追溯到源实例、原边、邻接面、型材截面、前后深度及遮挡区间。保留核定的洞口尺寸与位置、框扇主轮廓、分格梃、独立玻璃或饰面轮廓、窗套造型、必要接缝和开启线。若倒角、折边、回边或壳体叠边在该比例下共同表达一条边界，从同组已核实的主面或主边提取代表线。分别表达有依据的独立构造缝、安装净距及节点详图要求的差异。用途不明的线定位保留并登记待核。
3. **沿整圈生成。** 按原面外环、内环和型材截面恢复同一轮廓的完整关系，再提取采用的面边界。共面的无缝拼边在投影前消除，实际遮挡区间重新裁切。框边、分格梃和相邻轮廓在实际转角、T 接点或已证交界处用同一交点收口。随所属倒角或回边一起消除其短茬，保留有据的短边及真实断口。保持窗扇开口数量、内外环关系和分格拓扑，按实际可见形状成块。同型同尺寸且可见几何相同的参照可共用定义。
4. **核对跨块交界。** 一并展开同一洞口的窗框与独立窗套、门框与门扇以及相邻两扇。已确认数根近线共同表达同一交界且纸面只适合一道线时，在核定洞口边、窗套内缘或主要扇边选定代表线，由原图层归属对应的构件表达。相邻轮廓端点接到该代表线上。窗体与窗套各自保留块参照、有效图层和共用洞口基点，洞口控制尺寸从已核定的平面与定位测点读取。
5. **四向保存重开验收。** 逐向逐洞口检查实际 DWG 和关联块展开后的合并几何，同时看目标出图比例及等比例前后局部对照。核对窗格数量与分格、主轮廓、独立接缝、真实遮挡、洞口尺寸和位置。检查同一边界残留双线、部分重叠、闭环误开、转角断头、贴边短茬、分格梃错误承接及跨块接点。按洞口记录处理依据、采用边、去除区间和重开结果，将已查明的问题在同一轮出图内改正。验收同时核对框扇与套线的有效图层、块基点和可选取性。

刘府复修验证了两类漏查。有的窗格双线出自同一个源倒角，有的双线由窗框与独立窗套或相邻门扇同时表达同一交界。窗格倒角的模型投影间距约 10 mm，在 1:100 上约为 0.10 mm。这个实测值只用于解释刘府现象。新项目按自己的截面、比例和线宽判定。

### 柱脚实际落地与四向验收

先按实际构件实例区分首层室外落地柱、明确采用抬高平台承托的柱、上层阳台/退台柱及贴墙装饰。需落地的外壁柱按首层外柱核查，不能因名称叫“壁柱”就免查。室外完成地坪、室内楼面、勒脚顶、平台顶及结构基础标高分别记录；建筑柱脚落地不冒充基础埋深或结构承载结论。

- **共同控制参数：**逐柱登记实例ID、XY、柱类、应接地坪/承托类型、目标标高及来源、模型柱基底、柱身起点和分段、实际差高及处理状态。首层外柱以该柱位已核定室外完成地坪为目标；坡地或分台地按柱位取局部值，不把上一项目的高差或一个全图常数套用。基准缺失时明确待核，不能默认取室内零点。
- **平台条件：**仅在本项目明确设计为抬高平台承托时，采用对应平台完成面并记录范围、标高和依据。用户已要求该类柱落室外地面时，整块勒脚/台基的模型顶面不能作为替代依据。上层柱仍按真实楼板、梁或平台承托，不将所有上层柱直接拉到首层地面。
- **先修模型及收口：**同一实例的四向柱脚由同一地坪参数驱动。改变柱基底后，重算柱基、柱身分段、柱带连接及相邻勒脚/平台收口；核对实际平面进退、交接和可见范围。模型已经下伸、却被错误的整块台基遮到室内零点，也不能称室外落地已通过。先修宿主范围及遮挡关系，不靠二维补竖线、挪地线或强制露线制造落地。
- **四向交付核对：**建立“实际柱实例×方向”的应有/实有记录，从交付块参照及子实体追回三维柱脚，分别记录模型真实最低标高、该向实际可见最低标高、局部地面/承托、遮挡物及露出区间。先扣除立面排版偏移并统一单位，不能将CAD排版Y直接当建筑标高。柱脚被前景真实遮挡时单列证据，不把较高处的可见柱段最低点当模型柱底，也不为凑齐四向露脚补穿透线。
- **验收条件：**逐柱比较模型建筑柱基底与其已核定目标标高，并在各实际露脚方向检查落地轮廓和勒脚收口；数值容差按本项目单位及计算精度记录，不能吞并真实高差。柱脚接上室内零点线、勒脚顶线而形成闭合轮廓，仍可能落地点错误。“无悬空端点”、块展开一致或AUDIT通过不能替代此项。无依据、差高未解或错误遮挡未修的条目保持未通过，不写成全部柱已落地。

防复发核验至少覆盖：首层柱接上室内零点但室外更低；同类柱分别由不同模板生成；模型已下伸但被错误台基遮住；某方向仅露高处柱段；上层真实承托；坡地局部地坪及不同项目单位/高差。分别核对目标选择、模型参数和交付可见性，不只检查端点是否连通。

## 5. 可追溯记录与验收

每条异常线/断口至少记录：

- 项目、输入版本/哈希、单位、方向、交付实体句柄、块参照与嵌套路径、子实体或多段线段索引；
- 实际构件实例ID、宿主、原生句柄或图像依据、三维原边ID/端点、几何版本；
- 线的表达类别、最终邻接面/造型依据；发生截断时的遮挡面ID、深度、参数区间和交点；
- 异常坐标、实际尺寸/露宽、原因、修正依据、处理结论及效果图回核/平面反核/投影/导出状态。

平面、截面和剖面必须同时与源图/设计依据核对；从同一错误模型自动生成四张相互一致的图不能自证。字段缺失或原边无法追回时标明追溯限制，不能编造来源或写成已通过。

分别报告：①建筑依据与构件组合，②最终几何/拓扑，③四向可见线及端点，④清理成块，⑤原生保存重开及展开保真。几何比对应包含新增和丢失两类差异，不能只比较数量或单向最近距离。任一层未解决时，准确说明范围；“零重线”“AUDIT零错误”不能代替其他层通过。

## 6. 跨项目及历史成果复核

- 每个项目重新核验源版本、单位、方向、坐标变换及已确认条件。旧快照须哈希一致；确认缓存可用后，旧生成结果仍需按本规则复核。
- 无屋面/构件最终面或原边记录的旧成果：先从实体和来源建立可追溯候选，不用线段标签反推为已确认事实；必要时从本项目原图重建受影响部分。
- 已确认的不同坡度、真实退台、特殊节点和项目授权继续有效。不得继承其他案例的截面、坡度、屋脊高度、包柱厚度、坐标位移、删线结论或固定数值容差。
- 验证覆盖应包含共面无缝、真实折角/有据接缝、高低或异坡屋面、部分遮挡、真实小间隙、异形柱、不同单位/源版本变化等实际相关情形；只在本案通过不能声称所有旧DWG已修复。
