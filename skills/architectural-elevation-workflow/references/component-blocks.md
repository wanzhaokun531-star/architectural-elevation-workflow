# 构件块与碎线处理

## 建模及归属

- 为每个物理实例记录`id/kind/anchor/parameters/source`。同一型号可以出现多个实例；不能把`FRONT-PILASTER`这样的类型名当作所有柱的共同实例ID。
- 柱ID可关联楼层、实际中心及起止标高；窗关联原生句柄；线脚按连续段或实际构造段编号。先记录归属再投影，不能先全局去重后再猜哪些线属于哪个构件。
- 新增装饰用显式项目参数与模数，例如按本项目选择1、5或10mm；比例结果须落实成可编辑设计尺寸。源图真实73.5mm一类数值不作全图取整。显示精度设0不等于实际坐标没有小数。
- 发现5mm一类短柱线先查它是否从托件与檐板的真实间隙中露出；修正接缝关系，不盲删所有5mm线。

## 清理边界

先统一单位与计算基准；原图离原点很远时在共同局部坐标中计算，另存源坐标变换。一个洞口的所属墙面、中心、宽高、窗台高只定义一次，框、套和邻接墙段据此推导。洞口宽、框外宽和装饰外宽分别标识。逐轴核对墙段与洞口之和、墙垛净宽及跨层关联，不能逐段取整凑齐总长。

先修正三维构件的接缝、深度和遮挡，再清理投影线：没有设计分缝的共面内部拼边不输出，被窗套/柱/檐口遮住的背后边只裁去遮挡区间。跨实例的重合轮廓先明确归属，不能仅靠全局去重猜测所有权。本工具不执行以上语义判断或隐线计算。

在“实例＋立面＋图层”范围去除重复及近零线，合并重叠共线区间，连接无分支的连续轮廓为多段线。不得跨越实际遮挡断口，也不得把相邻不同构件合成一个块。

数值噪声容差与设计模数必须分开。本工具以mm输入，坐标归一到小数后6位，仅允许0.001mm以内的数值缝隙合并；真实2mm缺口、短附着转角等仍保留。其他单位先统一并核实精度，不能直接套用。

真实圆弧/椭圆如已知解析参数，宜输出ARC/ELLIPSE/CIRCLE；只有采样线段时可先连接成可编辑轮廓，但不得声称它已恢复为解析曲线。

小数分类处理：`900.0000001`等确认的浮点尾差按数值容差归一；新增装饰的`158.4`等比例结果按本项目模数落实并重建；源图真实小数保留或按本项目授权协调；斜面/曲线/遮挡交点保留所需精度。检查实际洞口宽高、墙垛净宽和柱宽，不用整数标注或坐标是否带小数代替尺寸验收。门洞、门扇和门套的整数主要尺寸在成块前按[默认出图规则](../SKILL.md#默认出图规则)核定并落实到几何。

## Python接口

用Python导入技能目录的`scripts/component_blocks.py`，不要把模块文件当独立命令执行。依赖`ezdxf`；先检查当前Python环境。

- `module_dimension(value, step=5)`：仅用于已授权的新增装饰参数。不会自动应用到源坐标。
- `clean_segments(lines, gap_tolerance=.001)`：每条线为`(start_xy,end_xy,layer)`；保留图层，清理共线重叠。
- `chain_paths(lines)`：连接连续轮廓，不穿越分支或真实缺口。
- `ComponentBlockExporter(doc)`：文档应先设置正确单位、图层及文字样式。工具从现行立面补充执行参数读取用途层与已确认层色；柱式、线脚和托件归线脚层，栏杆归栏杆层。只归一当前类型已知的旧层别名，混合用途显式层仍须按原边/邻接面识别，不能只凭块kind强改所有成员。
- `exporter.add(instance_id, kind, view, origin, lines, parameters, source_id)`：`origin`和线段都在同一已排版的二维世界坐标；返回主模型空间 `INSERT`。窗套随同调用以独立模型空间 `INSERT` 生成，可在 instances 中按 opening_instance_id 对应。调用前按原实例分离框扇和套边线。
- `kind`可用`window/door/column/moulding/railing/steps/corbel`。常用参数有`width/height/paired`等，位置和楼层等身份信息不参与同型块共享。
- `exporter.instances/definitions/stats/expected_segments`提供块索引、复用及几何核对依据。
- `world_segments(doc)`展开嵌套块和直线多段线，解析0层继承，用于本工具输出的检查。它遇到解析曲线或带bulge多段线会明确报不支持；不能忽略这些实体就宣布完整核验。

修改工具后可用Python运行`tests/test_component_blocks.py`，检查共线去重、真实缝隙/源小数保留、轮廓连接、块定义复用、不同尺寸及遮挡变体分离和编辑联动。

## CAD块要求与使用

- 输出真正`BLOCK/INSERT`，不是GROUP、整立面大块或原封不动把碎线换个容器。
- 相同类型、设计参数和局部可见几何才共享定义；不同遮挡变体用不同块名。基点靠近构件实际定位基点，插入比例默认1，避免非均匀拉伸柱帽/线脚。
- 块名包含类别、主要尺寸及稳定后缀。窗框、窗扇和分格与窗套分别生成可直接选取的模型空间块参照。两块沿用同一洞口定位基点、视向和来源，使用 opening_instance_id 关联。窗体归 A-立面门窗，窗套归 J-LM-立面线脚1-0.18；无可见窗套时不补空块。柱面轮廓装饰可嵌套为子块；主要几何可0层/BYBLOCK，确有需要的语义分层保留。
- `ELEV_COMPONENT`记录实例、来源、方向及参数；配套CSV/JSON索引提供实际块名与参照句柄。尺寸记录只是元数据，不是动态参数驱动。
- 在CAD中用`BEDIT`修改块定义，同名参照联动；只改一处时先另存新块定义并替换该参照。不同可见变体不会自动联动。不要承诺跨四立面三维参数联动。

## 交付核验

1. 实际窗、柱、线脚等是否为模型空间块参照；是否误把多实例装入一个块。
2. 检查普通块及嵌套块中的重线、零线、连续性；保留真实节点和短边。
3. 先逐项回核效果图，再用更新稿反核平面；源图真实坐标、门窗及标高的改动有依据。
4. 核验所有块定义、参照名称/位置/比例/旋转、局部几何、图层及XData，展开后世界坐标与投影输出一致。
5. 抽选重复块，编辑一份定义确认多个参照几何变化；不必修改用户交付原件。
6. 原生保存、重开及审计；交付中保留INSERT/LWPOLYLINE等可编辑实体。按当前项目的填充模式核对块内外的填充及遮挡。柱式和门窗套归线脚层，门窗框扇和分格保留门窗层；展开检查有效层。
7. 输出带实例ID、方向、坐标及原因的专项清单：重复线、近零线、异常短线、非预期断口、遮挡穿线、新增设计尺寸模数异常、门窗与墙体尺寸链差异。短线阈值只用于发现疑点，不作自动删除依据；逐项修正或注明真实构造/源数据/待定原因。

## 输入有效性与断口追溯

本工具清理线段和导出块，不判断源构件是否应存在、共面内部线是否应保留、遮挡截断是否合理。不能用工具测试通过或块展开一致宣布四向线条正确。遇到断线/乱线，先按[最终几何、屋面邻接与四向断线核查](geometry-topology.md)建立最终边、截断证据和交付实体追溯，再输入本工具；保留嵌套路径、子实体/线段索引与原边映射。跨实例归属变化须记录，并分别核对缺边和新增边。

调用方须记录本项目清理容差的单位、来源和适用范围。.001mm及六位小数是本工具的数值能力约束，不是建筑缝隙判据。clean_segments(..., gap_tolerance=0)可用于不桥接正间隙的清理；当前ComponentBlockExporter.add()内部仍采用默认清理容差，不能声称它会自动保护更小的已知真实间隙。遇到该节点须先选择能保留已证间隙的导出路径或为本项目明确扩展调用接口，并重新核验；不得按默认容差吞并后宣布通过。
