# 建筑施工图标注规则

将用户已确认的标注约定用于不同项目，输出可定位、可核验的尺寸、轴号、标高和文字。这里是用户的制图规则，不能当作国家规范条文。平面以现行主汇编为唯一规则来源，由本 Skill 同步适用条款，现行平面包含2026年11月11日确认的尺寸同侧无引线、门号200净距及碰撞换侧、模板A-WINDOW-TEXT、+0.000和一层室外台阶漏项检查。

## 读取适用规则

- 所有任务先读 [共用核验与规则差异](references/common.md)，确认单位、适用范围和待补参数。
- 平面任务读 [平面规则](references/plan.md)。先读[模板强规则](references/template-standard.md)，尺寸/轴号只能复制拉伸真实模板对象并保护完整依赖；其他文字、编号、图层和打印按模板书面表。包括外围三道及四道虚拟排布参考（不生成Defpoints实体框）、室内平开门按墙厚核标准门垛、室外台阶细部尺寸、门廊及阳台柱双向截面尺寸、露台阳台栏杆及反坎完整性、墙柱及主梁轴线、门窗编号、房名、楼面标高和层色。
- 立面任务读 [立面共用标注规则](references/elevation.md)，包括屋面横向控制线、外墙竖轴、主标高接第二道尺寸和近邻下标高翻转。屋面填充和柱式、门窗套归层见 architectural-elevation-workflow 的立面专项。
- 剖面任务先读同一份 [立面共用标注规则](references/elevation.md)，再读 [剖面继承范围和独有要求](references/section.md)。与旧剖面标注冲突时执行现行立面共用规则；剖切构件、材料、填充及专用房名要求继续按剖面自身规则。
- 查来源时读 [来源与版本](references/provenance.json)。原路径只作溯源，使用本Skill不要求这些路径存在。详细规则已随Skill附带。

## 应用方式

平面轴线先逐根确定服务构件、角色和有效起止，区分主轴、主体墙轴、门廊阳台柱轴及局部定位轴；主轴只在自身确认范围连续，不把所有有轴号的轴统一贯穿整栋包围框。偏心墙柱轴可在相关交接轴处分区表达，保留真实轴位及有效尺寸测站。局部无墙、门洞或轴圈隐藏不自动截断既定主轴；轴线连续不据此认定或生成主梁。独立线范围、轴号引线和尺寸测站分别核验，具体执行plan.md的PA06至PA10。

平面分别建立统一逻辑轴网、各侧轴号显示清单及有效尺寸测站。随包 PD16、PA22 至 PA26 由平面主汇编生成。按 PA24 同侧联合排版及折引线回接，真实轴位和尺寸测站按 PA26 独立核验。先按 PA26 配准，再按 PA22、PA23 核屋面投影与共同柱，按 PA25 核有效轴和退出项，按 PD16 生成外围尺寸，保存重开后按 PA26 复验。按 PA11–PA21 核近邻柱、共轴及独立柱轴、局部隔墙测点、分侧显示、原轴处置、跨层编号与投影接合。有效轴可按实际投影关系引出，不要求构件碰到最外墙边。隐藏轴圈和该侧专用引线，不删除逻辑轴或有效尺寸测站，也不因此合并墙柱偏心段。项目示例编号及偏心值只解释本例，不能套用于其他项目。

1. 从当前项目读取图种、绘图单位、出图比例、楼面零点、实际轴网、构件测点、层高和真实文字资源。按任务读取相关规则，不把案例坐标、句柄、层高或门宽当作通用常数。
2. 分清建筑实际长度和排版距离。门垛净宽按实际毫米量取，不随比例变化。表内1:100排版距离按纸面毫米控制；模型距离＝纸面毫米×比例分母÷每绘图单位对应毫米数。标高值以米表示。
3. 实测适用基准轴线、尺寸界线可见起笔端、尺寸基线、轴圈边或圆心、标高三角尖。平面外围有承担独立定位的外侧门廊柱或阳台柱轴时，从对应外侧柱轴起算。按 PA11 归并的柱在该方向采用外墙轴。已确认屋面檐边影响本侧常规排布时，按 PD16 采用实际檐边。三道尺寸、辅助框及轴号共用本侧选定基准。仅台阶凸出时沿用常规墙柱轴。立剖面按各自共用参考执行。DIMEXO等显示偏移须换算，界线尾段另计。平面总尺寸线至轴圈量近边；立面和剖面底部量圆心，不能混用。
平面第一道总尺寸和第二道轴间尺寸须覆盖本侧有效外墙轴及独立定位的门廊柱、阳台柱轴。PA11 归并方向以外墙轴为测站，必要的柱局部定位按 PD11 从实际柱边取点。两道采用同一首末边界；外侧有效柱轴不能裁回外墙范围。轴圈隐藏不代表轴位无效，真实柱墙轴间定位段须保留，分段之和与总轴距闭合。第三道按实际洞口及必要墙段，不机械延长。

4. 需要改图时，按当前任务授权修改真实对象、几何或排版。天正尺寸、轴号、标高和图名保持真实业务对象与可编辑关系；实际构件约束与规则冲突时先列明具体冲突，不仅改显示数字来伪造通过。单纯整理规则或解释规则不自动修改DWG、源码或安装包。
5. 对修改范围核对测点、测值、连续链、层色、文字及覆盖清单；做了DWG修改后保存重开，并检查最终图面。将规则更新、DWG落实、插件源码实现、正式安装包接入分别记录，只有实际核验过的结果才报告完成。

缺少原生CAD编辑能力时，可以完成规则解释、参数整理或检查清单；明确尚未执行的图纸操作，不把普通线文替代品交付成真正天正对象。未指定的字高、符号参数、轴线归并容差和打印线宽从适用参考读取，无法确定时列待核对。

## 维护这套规则

用户当前明确要求优先于本快照；同范围内新的明确确认覆盖旧值，案例说明不能覆盖通用规则。只更新获准的范围，保留其他图种的差异。

修改立面共用标注时同步核对剖面继承项，直接维护共用的elevation.md；section.md仅保留剖面差异，避免另存一份过期共用间距。修改平面不能连带覆盖立剖面。

同步维护相关参考及来源版本；若项目还保留汇编Word或外部规则文件，按本轮任务要求同步，并分别说明哪些成果已更新。Skill被复制到其他电脑后按其自身目录解析相对链接，不依赖作者机器路径。

## 使用示例

“按这套规则核对1:100剖面外围标注”：读取共用核验、立面和剖面参考；以本侧实际外墙轴线核对侧向五段及三角尖，底部800量到轴圈圆心；标高取当前项目真实控制高度和米制三位小数，逐侧核对覆盖。剖面填充及构件表达保持其独有要求。
